# Security Policy

## Supported versions

Seules les versions publiées (tags) sur la branche `main` sont supportées.

## Reporting a vulnerability

**NE PAS ouvrir d'issue publique** pour signaler une vulnérabilité.

Utilisez le rapport privé de vulnérabilité GitHub :
https://github.com/foXaCe/HA-Proxmox/security/advisories/new

Délai de réponse cible : 7 jours.
