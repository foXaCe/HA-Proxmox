# FAQ

**L'intégration est-elle compatible multi-nœuds ?** Oui — tous les nœuds visibles par l'utilisateur sont surveillés.

**Token ou mot de passe ?** Le token est recommandé (pas de mot de passe stocké). Le mot de passe est stocké chiffré dans la configuration HA.

**Pourquoi certaines entités sont désactivées ?** Les entités de diagnostic sont `entity_registry_enabled_default=False` (activables dans Paramètres → Entités).
